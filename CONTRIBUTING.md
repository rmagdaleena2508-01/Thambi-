# Contributing to Thambi

Thank you for helping. Thambi is in early development for the IDEA//FORGE hackathon, so the most useful help right now is:

1. **Correcting authority contacts.** If a helpline, portal or email in Thambi is wrong or outdated, open an issue with the **Wrong authority contact** template. Please link an official government source.
2. **Telling us about a real problem.** If you live in Tamil Nadu and have struggled to get a civic problem fixed, open an issue and tell us what happened. It helps us design for real people.
3. **Tamil language review.** Help us make the Tamil text natural and clear.

## Rules for data

- Authority contacts must come from an official government source. Unofficial lists are leads only.
- Never add the personal phone number of an individual officer. Only office channels.
- Never add invented reports presented as real.

## Code

Code contributions will open once the first version is built. Please keep changes small and explain them in plain words.
