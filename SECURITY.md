# Security policy

Thambi stores people's civic reports and the routing data that decides where those reports go. We take both seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: go to the **Security** tab of this repository and choose **Report a vulnerability**. Include:

- what you found and where,
- steps to reproduce it,
- what an attacker could do with it.

We will reply as soon as we can and keep you updated until it is fixed.

## What counts as a security issue

- Changing a report's status, priority or history without permission
- Editing or deleting someone else's report or comment
- Voting more than once on the same report
- Reading reports that are hidden or under review
- Seeing private data: email addresses, original photo location or time
- Changing the authority directory without permission
- Getting server secrets or keys

## What is not a security issue

- A wrong or outdated authority phone number or email. Please open a normal issue using the **Wrong authority contact** template.
